Facebook integration for the social media management framework of Odoo.

Connect a Facebook Page to Odoo and schedule text, image, multi-image
and video posts.

**Table of contents**

.. contents::
   :local:

Usage
=====

To use this module you need a Facebook developer app and a Facebook Page
you manage.

Go to *Social Media > Configuration > Social medias*, click *Associate
account* on Facebook and fill in your App ID and App Secret.
